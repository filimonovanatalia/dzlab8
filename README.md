##  Условие задачи (29%26=3 => 3 вариант)
## Задание 3
Вычислите с использованием цикла `for` значение ряда, для заданных пользователем значений `a` и `n`:

$$
S = \frac{1}{a} + \frac{1}{a(a+1)} + \dots + \frac{1}{a(a+1)\dots(a+n)}
$$

## 1. Алгоритм и блок-схема
##  Алгоритм 
1. **Начало**.
2. **Объявить переменные**:
   * `a` (вещественное) — параметр ряда.
   * `n` (целое) — количество шагов.
   * `sum` (вещественное) — для накопления суммы (инициализировать `0.0`).
   * `term` (вещественное) — для текущего члена ряда (инициализировать `1.0`).
3. **Ввод данных**: запросить у пользователя значения `a` и `n`.
4. **Проверка условий**: если `a == 0`, вывести сообщение об ошибке и завершить программу (так как будет деление на ноль).
5. **Инициализация цикла**: задать счетчик `i = 0`.
6. **Условие цикла**: Пока `i <= n`, выполнять шаги 7 и 8.
7. **Вычисление**:
   * Вычислить текущий член: `term = term / (a + i)`.
   * Добавить его к сумме: `sum = sum + term`.
8. **Увеличить счетчик** `i` на 1 (`i = i + 1`). Вернуться к шагу 6.
9. **Вывод результата**: вывести значение переменной `sum` на экран.
10. **Конец**.
